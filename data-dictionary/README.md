# AegisTrace Normalized Event Schema

| Field | Meaning |
|---|---|
| timestamp | Event time when available |
| event_id | Source event identifier |
| host | Host/device name |
| user | User/account |
| source_ip | Source IP |
| destination_ip | Destination IP |
| process_name | Process/executable |
| command_line | Process command line |
| event_type | Event/action/category |
| url | URL |
| domain | Domain |
| hash | File hash |
| raw_event | Original parsed record retained for context |
