# Presentation Notes

Suggested final demonstration order:

1. Problem statement and AegisTrace objective
2. Authentication and role-based access
3. Upload CSV/JSON telemetry
4. Parsing and normalized event schema
5. Detection feed and 24-rule library
6. Rule Testing demonstration
7. IOC extraction and IOC investigation
8. Run HUNT-001 and HUNT-002
9. Create an analyst-confirmed incident from a real detection
10. Response Playbooks and internal blocklist workflow
11. MITRE ATT&CK coverage
12. Reports Center and Executive Summary
13. Admin controls and Audit History
14. Limitations and future work

Important wording: detections are findings, not automatic proof of compromise; IOC extraction is observation, not reputation scoring; AegisTrace does not automatically change firewall or endpoint configuration.
