# Brute Force Response

**Mapping:** T1110

## Steps

1. Review failed authentication events.
2. Identify affected user and source IP.
3. Check whether the source targets multiple users/hosts.
4. Review successful logons after failures.
5. Validate expected vs suspicious activity.
6. Recommend account protection or network controls only after analyst confirmation.
7. Preserve evidence and create an incident when escalation is justified.

> Guidance only. AegisTrace does not automatically change endpoint or firewall configuration.
